# AI 창작자 홈그라운드 — 제품 백로그

포지셔닝: **"AI 영상 창작자의 본진"**. 유튜브가 방치하는 AI 영화·AI 드라마
창작자에게 제작→공개→수익 한 바퀴를 파는 플랫폼. vravra 일반관과 AI관은
선반 분리 + 큐레이션으로 신뢰도를 지킨다.

원칙: AI 라벨은 숨기지 않고 자랑한다. 메인 노출은 심사 통과작만.

## Epic 1. AI Originals 선반 (P0) — DONE 2026-11-20 (E2E 그린)
- 별도 `/ai` 시네마관(빌보도+시리즈/선정작/쇼츠 레일) + 카드·시청 배지 (`AiBadge`: tool/approved/size)
- 영상 메타 `ai_generated` + `ai_tool` (업로드·PATCH 입력) + `ai_review_status`/`ai_review_note`
- AI관/일반관 분리 (Originals 선반 + 홈/쇼츠 AI 제외), `/series/[id]` 시네마 상세

## Epic 2. 시리즈·시즌 구조 (P0) — PARTIAL
- DONE: 시리즈(시즌→회차) 모델 + attach/detach + 완결 전환 + 정주행 UI(회차 패널, 다음화 우선 up-next, 자동재생)
- MISSING: 시리즈 팔로우 + 새 회차 알림
- MISSING: 완주율 집계 (수익 배분 근거 지표)

## Epic 3. 큐레이션·심사 파이프라인 (P0) — PARTIAL
- DONE: 심사 큐 API (제출 → 심사중 → 선정/반려) + 스튜디오 제출 UI + 관리자 심사 페이지 + 내부 심사메모
- MISSING: 심사 기준 문서화 (스토리성, 기술 완성도, 표절·얼굴/목소리 권리)
- MISSING: 선정작 메인 노출 슬롯 + 심사위원 코멘트 공개
- 제약: 시리즈 `AiOriginal`은 API로 지정 불가 (승인된 회차가 속하면 자동 지정), `ReviewAI` step-up 미적용

## Epic 4. 권리·클레임 강화 (P1)
- AI 전용 클레임 사유 (학습데이터, 캐릭터, 음성 합성)
- 권리자 선등록(얼굴/목소리 지문) + 자동 매칭 플래그
- 이의제기 fast-track (48h SLA 목표)

## Epic 5. AI 창작자 수익 (P1)
- 시리즈 완주율 기반 정산 (조회수 가중 + 완주 보너스)
- Originals 선정작 프로모션 부스트 + 정산 대시보드 항목 추가
- 후원/멤버십과 시리즈 얼리액세스 연동

## Epic 6. 제작 연동 (P2)
- 스튜디오에 AI 제작 메타 입력 (프롬프트 로그, 모델 버전, 편집 툴)
- 프롬프트→시사회: 비공개 프리뷰 링크 + 피드백 댓글
- 시리즈 일괄 업로드 (회차 예약 발행과 연동)

## 지표
- AI관 주간 활성 창작자 수, Originals 선정→완주율, 시리즈당 평균 회차,
  클레임 처리 리드타임, AI관 이탈률 vs 일반관
