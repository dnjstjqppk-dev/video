## 1. 핵심 명제 (3줄)

1. **정면 승부를 하지 않는다.** 범용 UGC 볼륨·추천 AI·글로벌 엣지에서는 유튜브를 이길 수 없다.
2. **AI 오리지널 버티컬에서 이긴다.** 심사 기반 큐레이션 + 창작자 시리즈 운영 + 플레이어 장인정신 — 유튜브가 방치한 영역에 전 병력을 집중한다.
3. **글로벌 확장은 인프라가 아니라 신뢰 순서다.** 도메인/인증/결제/준법이 먼저, 엣지/용량은 그 다음이다.

## 3. 정면으로 붙지 않는 영역 (인정하고 피한다)

- **범용 추천 피드 AI**: 데이터도, 팀도, GPU도 없다. 큐레이션(사람+심사)으로 우회한다.
- **쇼츠 볼륨 전쟁**: 쇼츠는 Originals 쇼츠(심사 통과작)라는 좁은 정의로만 취급한다.
- **글로벌 엣지 직접 구축**: Cloudflare(R2 zero-egress + Workers + Stream Live)에 얹는다. 직접 구축은 하지 않는다.
- **가격 경쟁**: 단위 경제(BENCHMARK §3, 월 $2,401 추정 — `가정`: 1만 MAU/45TB 기준, 실측 아님)를 무너뜨리는 무료 공세는 금지한다.

## 4. 글로벌 확장 로드맵 (게이트 기반 — 순서 엄수)

각 단계는 게이트를 통과해야 다음으로 간다. 현재 위치: **단계 0 완료, 단계 1 진행 전**.

### 단계 0 — 국내 검증 (현재, Mount Laurel) ✅ 달성

- 판정: d4964ea 전체 게이트 그린 + AI E2E 그린 + PG 14 마이그레이션 실적용.
- 잔여: OIDC 실테넌트(사용자 작업), DRM E2E, 라이브 DVR, 모바일 실연동.

### 단계 1 — 신뢰 확보 (순수 차단 해제, 코드 작업 아님)

| 게이트 | 내용 | 현 상태 |
| :--- | :--- | :--- |
| G1-1 | 정식 도메인 + Cloudflare Zone (brand.com) | 미보유 — 퀵터널+workers.dev |
| G1-2 | ZITADEL 실테넌트 + 운영 시크릿 주입, `GVP_ENV=production` + 데브토큰 off | 코드 준비됨, 발급 대기 |
| G1-3 | R2/Stream 실계정, Toss/Stripe 실가맹, 스토어 개발자 계정 | 전부 미충족 (감사 §3.2) |
| G1-4 | 개인정보·청소년·저작권 대응 문서(준법 체크리스트) 실효화 | 문서만 존재 |

### 단계 2 — PC 탈출 (단일 장애점 제거)

- API/워커를 호스티드 컴퓨트로 이전(컨테이너 → 매니지드), quick tunnel → named tunnel → 오리진 직접.
- PG를 best-effort에서 1차 저장소로 승격(현재 메모리 1차 + 7종 write-through).
- `infra/terraform`, `infra/kubernetes`의 placeholder 실값화 + CD echo를 실제 파이프라인으로 교체.

### 단계 3 — 미디어 실전 ( proof-by-load)

- k6 1k-CCU 실부하(현재 loopback 50동시), HLS 캐시· purging 실측, 라이브 인제스트 + DVR 실가동.
- DRM 실ライ선스 서버 연동(ClearKey → Widevine/FairPlay 실서버), 모바일 실연동 검증.

### 단계 4 — 리전 확장 (그때 가서)

- R2 + Workers는 리전 작업 없이 글로벌이라, 여기서 할 일은 **법무·정산·언어**다: 리전별 결제 수단, 세금계산서/인보이스, i18n(현재 ko/en 뼈대), 모더레이션 현지화.
- 엣지 컴퓨트(encoding 리전 분산)는 유료 전환율·시청 지표가 비용을 정당화할 때만.

## 5. 하지 않기로 한 것 (전략적 NO 목록)

1. NATS/Valkey/OpenSearch/ClickHouse를 "문서상 연결"로 처리하지 않는다 — 붙일 때 붙이고, 그전엔 목표로 표기한다.
2. 추천 알고리즘을 직접 만들지 않는다 (단계 4까지).
3. 자체 CDN/인코딩 팜을 짓지 않는다.
4. MAU water-fall 목표를 세우지 않는다 — Originals 선정작 수·정주행 완주율·창작자 유지율이 북극성이다.
