## Data ownership

- **Identity:** users, organizations, roles, membership.
- **Catalog:** channels, videos, media metadata.
- **Social:** comments, playlists, subscriptions, community.
- **Media:** upload sessions, assets, transcoding jobs.
- **Live:** streams, sessions, chat.
- **Analytics:** daily materialized rollups; raw playback events live in ClickHouse.
- **Advertising:** campaigns, creatives, impressions, invoices.
- **Finance:** subscriptions, payments, refunds, ledger, payouts.
- **Partner & rights:** contracts, ownership evidence, claims, disputes.
- **Operations:** moderation, policy, flags, idempotency, outbox, logs.
